# OpenCode

Target ID: `opencode`.

- Agent output: `~/.dotagen/.generated/opencode/<name>.md`
- Agent link: `~/.config/opencode/agents/<name>.md`
- Skill output: `~/.dotagen/.generated/opencode/skills/<name>/`
- Skill link: `~/.opencode/skills/<name>/`

OpenCode agent output has a derived `description` and `mode: subagent`
frontmatter. Skill output has `name` and `description` frontmatter.
