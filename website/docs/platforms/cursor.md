# Cursor

Target ID: `cursor`.

- Agent output: `~/.dotagen/.generated/cursor/<name>.mdc`
- Agent link: `~/.cursor/rules/<name>.mdc`
- Skill output: `~/.dotagen/.generated/cursor/skills/<name>/`
- Skill link: `~/.cursor/skills/<name>/`

Cursor agent output uses `description`, optional `globs`, and
`alwaysApply: false` frontmatter. Skills render with `name` and optional
`description` frontmatter.
