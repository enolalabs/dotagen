# Gemini CLI

Target ID: `gemini-cli`.

- Agent output: `~/.dotagen/.generated/gemini-cli/<name>.md`
- Agent link: `~/.gemini/agents/<name>.md`
- Skill output: `~/.dotagen/.generated/gemini-cli/skills/<name>/`
- Skill link: `~/.gemini/skills/<name>/`

Agent output includes `name`, optional `description`, optional `tools` as a
YAML list, and optional `model` frontmatter. Skill output includes `name` and
optional `description`.
